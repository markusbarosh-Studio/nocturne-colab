# Nocturne – Colab-Notebook

Standard-Notebook für **Markus Barosh Nocturne** (Version 1.1.0). Nocturne öffnet es mit einem Klick in Google Colab;
dort rechnet ComfyUI auf der Grafikkarte, Nocturne steuert alles. Du musst hier nichts herunterladen oder ändern.

- Nocturne öffnet immer eine **fest eingefrorene Fassung** (Commit). Änderungen an diesem Projekt erreichen Nocturne erst mit einer neuen App-Version.
- Das Notebook enthält **keine persönlichen Daten und keine Modell-Liste**. Welche Modelle geladen werden, schickt Nocturne nach dem Verbinden direkt in deine eigene Colab-Sitzung.
- Schlüssel (HF_TOKEN, CIVITAI_TOKEN) liegen nur in deinen Colab-Secrets und bleiben im Arbeitsspeicher deiner Sitzung.
- Die Verbindung ist mit einem geheimen Schlüssel geschützt, der in jeder Sitzung neu entsteht.
- Kostenloses Colab erlaubt die Arbeit über eine Web-Oberfläche wie ComfyUI nicht – nutze Colab Pro oder „Pay As You Go“.

Wer selbst Hand anlegen möchte, nimmt in Nocturne die Profi-Option „Eigenes Notebook verwenden“ (eigene Kopie im eigenen Google Drive).

**Fremdsoftware**, die das Notebook zur Laufzeit in deiner Colab-Sitzung lädt (nicht Teil dieses Projekts):
ComfyUI (GPL-3.0, github.com/comfyanonymous/ComfyUI), cloudflared (Apache-2.0, github.com/cloudflare/cloudflared),
Erweiterungen und Modelle nach deiner Auswahl in Nocturne – es gelten deren Lizenzen.

**English:** Standard Google Colab notebook for Markus Barosh Nocturne. Nocturne opens a pinned version (commit) of this file;
